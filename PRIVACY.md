# Privacy policy

This project is a personal automation tool. It is used only by its owner, to upload videos to the owner's own
YouTube channel and read that channel's own statistics.

- **What it accesses:** only the owner's own YouTube channel, using permissions the owner granted to their own
  Google Cloud project. It does not access anyone else's account.
- **What it stores:** the access credentials live only in the owner's private GitHub repository secrets. Nothing is
  sold, shared or published.
- **Third parties:** videos and statistics are exchanged with YouTube (Google) only. Script text is sent to an AI
  provider (for example Google Gemini) to write scripts; no personal data is included.
- **Other users:** the tool has no sign-up and collects no data from viewers or visitors.

Contact: open an issue in this repository.
